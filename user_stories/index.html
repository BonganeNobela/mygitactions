    User Stories

    User Story 1

    • Who: As a user
    • What: I want to be matched with a random pen pal from another country
    • Why: So that I can learn about different cultures

    User Story 2

    • Who: As a user
    • What: I want to securely sign up and log in
    • Why: So that I can access GlobeTalk

    User Story 3

    • Who: As a user
    • What: I want to apply filters like time zone or language preference
    • Why: So that my conversations are easier to understand and more relevant

    User Story 4

    • Who: As a user
    • What: I want to choose between a one-time message or ongoing correspondence
    • Why: So that I can control how committed I want to be

    User Story 5

    • Who: As a user
    • What: I want to send messages with a delivery delay
    • Why: So that I can experience the feeling of a traditional postal mail

    User Story 6

    • Who: As a user
    • What: I want my messages to be stored privately
    • Why: So that I can reread them whenever I want

    User Story 7

    • Who: As a user
    • What: I want to write a short anonymous intro about myself
    • Why: So that others can get a sense of who I am

    User Story 8

    • Who: As a user
    • What: I want to read anonymous facts about my pen pal (age range, hobbies, region)
    • Why: So that I can understand their background

    User Story 9

    • Who: As a user
    • What: I want to learn about region-based fun facts, holidays, or sayings
    • Why: So that I can appreciate cultural differences

    User Story 10

    • Who: As a user
    • What: I want to be able to flag inappropriate content
    • Why: So that I can maintain a safe environment

    User Story 11

    • Who: As a user
    • What: I want to block users who make me uncomfortable
    • Why: So that I can control who I interact with

    User Story 12

    • Who: As a user
    • What: I want all chats to be anonymous (no names or emails)
    • Why: So that my privacy is protected

    User Story 13

    • Who: As a user
    • What: I want a match screen where I can find new pen pals with filters
    • Why: So that I can start new conversations easily

    User Story 14

    • Who: As a user
    • What: I want an inbox to view my active conversations
    • Why: So that I can keep track of ongoing letter exchanges

    User Story 15

    • Who: As a user
    • What: I want settings and safety tools
    • Why: So that I can control who I interact with and feel protected
