# Scrum Methodology

## 1. Introduction

This project follows the **Scrum methodology**, an Agile framework for managing and completing complex software development projects. Scrum is particularly well-suited to our Virtual Pen Pals website because it emphasizes:

- Short, iterative development cycles (**sprints**)  
- Frequent reviews  
- Adaptability to change  

This ensures that our group delivers a functional and high-quality product within the set deadlines.

---

## 2. Why Scrum is Suitable for Our Project

Our development cycle consists of **four sprints** spread across approximately three months, each focusing on specific deliverables. Scrum allows our group to:

- **Break the project into manageable parts** – making it easier to meet deadlines.  
- **Receive and apply feedback early** – enabling course corrections without major rework.  
- **Maintain clear team roles and responsibilities** – ensuring accountability.  
- **Track progress visually** – using tools like Scrum boards or digital equivalents.  

Given that our sprints vary in length, Scrum’s flexibility ensures we can still deliver working features at the end of each sprint, regardless of duration.

## 4. Scrum Events Used in the Project

1. **Sprint Planning** – At the start of each sprint, the team selects the features and tasks to be completed, based on priority.  

2. **Daily Stand-ups** – Short daily meetings to discuss:  
   - What was done yesterday  
   - What will be done today  
   - Any obstacles faced  

3. **Sprint Review** – At the end of each sprint, the team demonstrates the new features to stakeholders for feedback.  

4. **Sprint Retrospective** – After each review, the team evaluates what worked well and what can be improved in the next sprint.

- Efficiently manage development tasks  
- Respond quickly to feedback  
- Ensure consistent progress throughout the project
